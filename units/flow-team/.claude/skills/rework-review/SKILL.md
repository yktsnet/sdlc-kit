# rework-review

PR 本文の `## 手戻り` を集め、繰り返す原因を Issue にする。節の書き方と原因の分類の正本は
`docs/ops/workflow.md`「手戻りを記録し、仕組みへ返す」で、ここはその手順である。

相談者として動く。**直さず、PR 本文も書き換えない。** 書き込むのは、user が採った候補の起票と、既存の Issue への
追記だけである。分類の誤りに気づいたら、束ねるときに読み替え、読み替えたことを一覧に書く。

## 1. 手戻りの節を集める

起点の日時を渡されたら、それ以降にマージした PR を読む。前回の終わりの日時を渡せば、前回の分を読み直さずに済む。
起点が無ければ、今日から30日前の日付を起点にする。起点は `YYYY-MM-DD` で、コマンドに直に書く。

```bash
gh pr list --state merged --search "merged:>=<起点>" --limit 1000 --json number,title,body \
  --jq '.[] | (.body | gsub("\r"; "") | capture("(?:^|\\n)## 手戻り\\n(?<s>.*?)(?:\\n## |\\z)"; "m") | .s) as $s
        | "### #\(.number) \(.title)\n\($s)"'
```

節が `なし` の PR は数えるだけにする。`Closes #` を持つのに節の無い PR は、番号を一覧の最後に添える。

```bash
gh pr list --state merged --search "merged:>=<起点>" --limit 1000 --json number,body \
  --jq '.[] | select(.body | test("Closes #")) | select(.body | test("(^|\\n)## 手戻り") | not) | .number'
```

## 2. 束ねて候補を選ぶ

各 PR の手戻りの表の行を、原因の分類ごとに束ねる。同じ分類の中で「仕組みで防げたか」が同じ欠け（同じ手順・同じスクリプト・
同じフック）を指す行を、同じ原因として1つにまとめる。言い回しが違っても、指す欠けが同じなら同じ原因である。

同じ原因が2本以上の PR に出たものを候補にする。1本の中で続いたやり直しは1回と数える。失った時間の大小は
基準にしない。時間は概算で、待ちが大半を占めることも多く、基準にすると判定がぶれる。

「実装者の不注意」の行は、`docs/ops/workflow.md` の分類の表にある読み替えに従い、読み替えたものだけを候補にする。

候補ごとに、次を確かめる。

- 直す先がすでに直っていないか。手戻りを記録した PR のうち一番新しいもののマージより後に、直す先のファイルへ
  入ったコミットを読む（`git log --since="<マージ日時>" --format="%h %cI %s" -- <直す先のファイル>`）
- 同じ主題の Issue が開いていないか（`gh issue list --state open --search "<主な語> in:title,body"`）

## 3. 一覧を見せて止まる

候補ごとに1行で並べ、扱いの案を付ける。

```
| # | 分類 | 原因（1行） | PR の本数 | PR | 案 |
```

案は次の3つのどれかにする。直す先は `docs/ops/workflow.md` の分類の表で引く。直し方は、検査（CI・フック・
スクリプト）にできるなら検査を選ぶ。skill や文書に文を足すと、長くなった分だけ読み落としが増える。

- Issue にする：直す先のファイルと節を添える
- 既存の Issue に追記：手順2で当たった Issue の番号を添える
- 見送る：理由を添える（すでに直った、リポの中では直せない、など）

一覧のあとに、読んだ PR の数・`なし` の PR の数・候補にしなかった行の数と、節の無い PR の番号を添える。
1本だけに出た原因（「実装者の不注意」を除く）も1行ずつ添える。user が選んだ行は候補に加える。

user は候補ごとに案を採るか替えるかを返す。承認を受けるまで起票しない。

## 4. 起票し、追記する

- Issue にする候補は、1件ずつ `issue-draft` の手順で起票する。本文の `根拠` に、手戻りを記録した PR の番号と行を書く
- 既存の Issue への追記は、追記する文面を見せて OK を受けてから `gh issue comment <番号> --body-file -` で書く

起票した Issue と追記した Issue の番号、見送った候補を報告して止まる。次に呼ぶときの起点として、今回読んだ範囲の
終わりの日時を添える。

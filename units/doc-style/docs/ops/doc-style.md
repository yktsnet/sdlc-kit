# 文書の書き方

このリポの Markdown（README・CLAUDE.md・PLAN.md・JUDGE.md・`docs/` 配下・PR 本文）と、
コード中の日本語コメントに当たる規範。

**規範の本体は `.claude/skills/jp-writing/SKILL.md` にある。** ここには、規範を各リポに置く
理由と、リポ固有に決めることだけを書く。

## なぜ書き手の手元ではなくリポに置くか

文体は、既存のファイルを真似て書けば揃うように見える。だが真似る先が無い場面がある。
リポジトリを起こした直後、全編を新規に書くとき、担当者が替わった最初の1本。成果物にしか
存在しない規則は、書き手が持ち込む既定に負ける。

だから `doc-style` は選ばせない。どの単位を入れても一緒に入る。

## このリポで決めること

以下は jp-writing が決めていない。リポごとに書き足す。

| 項目 | このリポの決まり |
|---|---|
| 見出しの言語 | `<日本語 / 英語見出し+日本語本文>` |
| 文体 | `<ですます / である / 混合>` |
| コミットメッセージの言語 | `<日本語 / 英語>` |
| README の言語 | `<日本語のみ / 日英併記>` |

コミットメッセージと PR の言語は**このファイルが正本**にする。CLAUDE.md には書かない。
言語の規約を複数箇所に置くと、片方だけ直されて割れる。

## 書かないもの

- 日付入りの履歴コメント（「2026-01 時点で〜」等）。経緯は git log に任せる
- コードを読めば分かることの説明。コメントは WHY が非自明なときだけ書く

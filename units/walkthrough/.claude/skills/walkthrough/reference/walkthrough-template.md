## この機能から作った理由

なぜこの機能を丁寧に説明するのか。中核と言える理由を書く。似た役割のもの（試作・旧実装）が
あれば、何が違うのかを1〜2文で添える。

## 入力と、出力までの経路

```text
入力の置き場           何が入っているか
        │
        ▼
処理の単位             何をするか
        │
        ▼
出力                   何が出るか
```

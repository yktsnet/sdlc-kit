# walkthrough

中核の機能を1本作り終えたときに、その機能が何を受け取り、どう判断し、何を出すかを書いた資料を置く。
実装の進みに理解が追いつかないまま積み上がるのを防ぐため、外の人（数か月後の作った本人を含む）に
説明できる形で書き、読む人が手元で同じ結果を再現できるようにしている。書き方は `/walkthrough` skill が持つ。

資料は実装と一緒に古くなる。すべての機能に作ると資料そのものが負債になるため、中核の機能に限る。
既存の機能に規則が足されただけなら、新しく作らずに該当する資料を直す。

## 一覧

どの機能もいずれ作り終えるので、予定も先に並べておく。

| 資料 | 機能 | 状態 |
|---|---|---|
| — | 機能の名前 | 予定（`PLAN.md` など計画の置き場の該当箇所） |

予定の行が中核でないと分かったら消す。残しておくと、作らないものが予定に見え続ける。
